# 📝 Sign-Up Flow Optimization Dashboard  

## 🎯 Objective  
The purpose of this dashboard is to analyze and optimize the **user sign-up journey** by tracking conversion rates, sign-up attempts, device/OS usage, error types, and login behaviors.  
It provides insights into **where users drop off** and what improvements can increase successful sign-ups.  

---

## 📂 Dataset  
- **Source**: Application sign-up and login logs.  
- **Period Covered**: July 2022 – February 2023.  
- **Key Fields**: Date Session, Signup Type, Login Type, Error Messages, Device, OS, Attempts, Success/Fail status.  
- **Volume**: 3,80,000+ login attempts, 1,16,000+ sign-up attempts.  

---

## 🔍 Key Insights  
- **Conversion Rate**: Average **26.8%** with peaks at **43%** in September 2022.  
- **Device Usage**: Desktop (44.14%) and Mobile (42.25%) dominate sign-ups.  
- **Operating Systems**: Windows and Android account for the majority of user attempts, followed by iOS and Ubuntu.  
- **Sign-Up Methods**:  
  - Google: 54,614  
  - Email: 23,319  
  - LinkedIn: 5,693  
  - Facebook: 5,211  
- **Login Errors**:  
  - Most common → *Invalid email or password!* (**382K+ cases**).  
  - Other issues include *popup closed by user, email already taken, password length errors*.  
- **Drop-offs**: A large number of users abandoned sign-up due to browser popups being closed or blocked.  

---

## 📈 KPIs and Metrics  
- **Sign-Up Conversion Rate (%)**  
- **Total Visitors → Free Conversions**  
- **Sign-Up Attempts (Successful vs Failed)**  
- **Error Frequency (Login & Signup)**  
- **Device & OS Breakdown**  
- **Channel Split (Google, Email, LinkedIn, Facebook)**  

---

## 📊 Charts and Visuals Used  
- 📉 **Line Chart** → Visitors vs Conversion % (by month)  
- 📊 **Bar Charts** →  
  - Sign-up Attempts by Device  
  - Sign-up Attempts by OS  
  - Sign-up Attempts by Signup Method  
- 🥧 **Pie/Donut Charts** → Share of successful sign-ups vs failed attempts  
- 📊 **Error Distribution Bars** → Frequency of login and signup errors  
- 📊 **Stacked Bars** → Signup outcomes by type (Google, Email, etc.)  

---

## ✨ Features  
- Drill-down by **time (month)**, **device type**, and **signup method**.  
- Segmentation by **error category** to identify major blockers.  
- Separate views for **Sign-up** and **Login flows**.  
- Error breakdown with **counts and root causes**.  

---

## ✅ Outcome / Impact  
- Identified **key bottlenecks** in user sign-up flow (e.g., email/password errors, browser popups).  
- Helped prioritize **UX improvements** (simplified forms, error handling, better social login integration).  
- Provided insights on **which signup methods (Google, Email)** are most effective.  
- Informed business decisions to improve **conversion rate from 26% → 40%+** in targeted months.
